================================================================================
MIDDLEWARE PIPELINE ORDER (Program.cs)
================================================================================

  Order matters! Each middleware runs in sequence. If a request is blocked
  by an earlier middleware, later ones never execute.

  1. Security Headers    → Adds security headers to EVERY response             → 200
  2. Request Validation  → Blocks malicious input (SQL injection, XSS)         → 400
  3. API Key             → Authenticates the calling application               → 401
  4. JWT Validation      → Validates Azure AD / Entra ID bearer token          → 401
  5. IP Filtering        → Checks client IP against whitelist/blacklist        → 403
  6. Rate Limiting       → Limits requests per time window                     → 429
  7. Request Throttling  → Enforces daily quota per client                     → 429
  8. Your Function       → Executes business logic                             → 200 ✅

  WHY THIS ORDER:
  - Security Headers first: OnStarting callback ensures headers on ALL responses
  - Validation next: Never process malicious payloads
  - API Key before JWT: Cheaper check first (string comparison vs token validation)
  - IP Filter after auth: Know WHO is calling before checking WHERE from
  - Rate/Throttle last: Only count validated, authorized requests
